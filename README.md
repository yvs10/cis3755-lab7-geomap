# Lab 7: Geomaps (CIS 3755)

Starter files for Lab 7. Follow the lab instructions document for the activities.

## Getting the starter code (no GitHub Classroom)

1. Click the green **Use this template** button above and choose **Create a new repository**.
2. Name it `lab7-geomap`, keep it **Public** (required for GitHub Pages), and create it under your own account.
3. Clone your new repository and open the folder in VS Code.
4. Serve the folder locally (for example the VS Code **Live Server** extension, or `python3 -m http.server`). Opening `index.html` directly from disk will NOT load `topo.json`.

## Files

- `index.html` – page with the `#geomap` SVG and the D3 v7 script tag
- `geomap.js` – your code goes here
- `topo.json` – US states TopoJSON (from `us-atlas`), used in Activity 1

## Branches and submission

- Activity 1: create and check out a branch named `activity-1`.
- Activity 2: create `activity-2` **from `activity-1`**.
- Deploy GitHub Pages from the `activity-2` branch (Settings → Pages → Deploy from a branch → `activity-2` / root).
- Submit on Canvas: the link to your repository and the link to your GitHub Pages site.
